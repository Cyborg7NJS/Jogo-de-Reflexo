# Jogo-de-Reflexo

Jogo simples de reflexo para dois jogadores.

Descrição
- A tela começa cinza.
- Depois de alguns segundos (aleatórios) a tela muda para verde.
- O primeiro jogador a clicar quando estiver verde ganha a rodada.

Controles
- Botões na tela: "Jogador 1" e "Jogador 2".
- Teclado: tecla `1` para Jogador 1 e tecla `2` para Jogador 2.

Regras
- Se um jogador clicar antes da tela ficar verde, é falso início e o ponto vai para o adversário.
- O placar é atualizado automaticamente.
